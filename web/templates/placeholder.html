How it gets built

The same shape as the run tracker, in this order:

core/schema.sql        tables and views
core/<section>.py      parsing, validation, formatting
core/<section>_queries.py    reads, returning plain dicts
core/<section>_mutations.py  writes
web/blueprints/<section>.py  these pages, for real
views/<section>/       the Streamlit side

The section already exists in config.SECTIONS, which is where both front-ends read their navigation from — so the sidebar entry, this page and the Streamlit equivalent all come from one line.
