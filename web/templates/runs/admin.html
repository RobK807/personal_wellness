Re-importing

Runs are matched on date, distance and elapsed time, so re-running the importer updates what has changed and adds what is new without duplicating anything or touching runs entered by hand.

python -m core.strava_import           # update from the sheet
python -m core.strava_import --rebuild  # discard imported runs and start again

Run it on a desktop: openpyxl opening the workbook needs more memory than the NAS has free.
